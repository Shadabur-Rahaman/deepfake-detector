# Contributing

1. Fork the repo and create a branch from `main`.
2. Run the backend with `uvicorn backend.app.main:app --host 127.0.0.1 --port 8000`.
3. Run the frontend with `npm run dev` inside `frontend/`.
4. Open a pull request with a short description of why the change exists.

Do not commit `config.env`, API keys, databases, uploads, or virtualenvs.
